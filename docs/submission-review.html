Project story

## Inspiration
A wrong cut does not always make a whole sheet unusable. The motivating question behind SecondCut is whether a camera can turn the material that remains into a compatible next step, instead of simply flagging a defect.

## What it does
SecondCut measures one flat cardboard blank on a printed calibration mat and finds a smaller rectangular panel that fits the visible material and the user's minimum dimensions. It supports shortened edges, missing corners, and deep notches. The prototype targets a two-panel cross-slot organizer insert. Both panels inherit the revised height, and both slots use the same entered thickness and half-height depth. A user must accept the plan before downloading a full-size SVG. A new photograph can then be checked against the accepted outline and slot. The companion panel requires separate stock.

## How we built it
The working local application uses Python, FastAPI, OpenCV 5.0.0, NumPy, SQLite, and a responsive JavaScript interface. OpenCV detects four ArUco markers, rectifies the photograph, segments the cardboard, preserves holes, and checks edge sharpness. A bounded rectangle solver applies a 2 mm edge allowance, respects dimension constraints, and removes dominated options. The controller selects recapture, replacement, or human review from the visual evidence. It is deterministic and does not use an LLM. Codex assisted with implementation, testing, documentation, and submission preparation.

## AWS architecture and current status
The repository includes a prepared AWS SAM container deployment for the OpenCV and planning backend on Lambda, private S3 evidence storage, and CloudWatch logs. AWS deployment has not yet been completed or verified. This draft does not claim a live cloud endpoint, COOL integration, or special-award eligibility.

## Challenges
A plausible-looking rectangle is not enough: it must stay entirely within the observed material, preserve holes and damage, and keep the companion slot compatible. Similarly, high silhouette overlap can conceal a missing narrow slot, so verification separately checks slot clearance. Browser testing also led to clearer trade-offs between recovery alternatives.

## What works so far
The local workflow supports capture, inspection, repair review, approval-gated template export, and recapture verification. Eighteen automated tests pass. Nine deterministic generated-image scenarios produce the expected recovery, replacement, or recapture decision. These are synthetic regression results, not real-world accuracy or material-saving claims.

## What we learned
Recovery is a constraint problem as well as a perception problem. Measurement uncertainty, compatible joints, user intent, and explicit rejection matter as much as finding the outline. A useful system must say when it cannot support the next cut.

## Limitations and next steps
The current prototype assumes flat matte brown cardboard aligned with a correctly printed A4 mat, even lighting, and a single visible blank. Thickness is entered manually. Warping, printed graphics, glare, arbitrary CAD, strength prediction, and cutting-machine control are outside scope. Verification checks visible geometry only. Physical cardboard assembly validation, AWS deployment, and the final team/demo video are pending.

## Related work
scrAPP already explores smartphone contour capture and scrap reuse, and MIT's Fabricaide supports material-aware design. SecondCut focuses on a bounded post-error recovery loop with compatible slot propagation and recapture verification. We do not claim a world-first algorithm.

Testing instructions

Current status: local prototype. AWS endpoint and final demo video are pending; do not treat this draft as a completed deployment.

1. Clone the repository. Use Python 3.12 and create/activate a virtual environment.
2. Install: python -m pip install -r requirements-dev.txt -c requirements.lock.txt
3. Run: python -m uvicorn secondcut.app:app --host 127.0.0.1 --port 8000
4. Open http://127.0.0.1:8000. Confirm OpenCV 5.0.0 in the header.
5. Select Missing corner, then Find my second cut. Compare repair dimensions, accept a plan, and download the SVG and inspection record.
6. Choose Try a synthetic repaired panel. It should report a geometry match while explicitly noting that physical fit remains unverified.
7. Inspect Too little left: expect replacement. Inspect Missing marker: expect recapture and no cutting template.
8. Run python -m pytest -q and python scripts/evaluate.py.
9. To test a real photo, print the supplied A4 mat at 100%, verify marker spacing, place a flat brown blank within the markers, and follow the field guide.

Built-in samples are synthetic. The companion panel requires separate stock. The output is an insert without base or outer walls. For AWS deployment instructions and pending verification steps, see infra/README.md.
